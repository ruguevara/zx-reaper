# zx-init

## Standard tape (ROM loader, headed blocks)

1. `python3 <zx-reaper>/tools/zxinit.py game.tap game-re/` (add `--rzx play.rzx` if you have one).
2. It must end with `IDENTICAL`. Read its TODO lines and `re/notes.md`.
3. `tools/zxdoctor.py` must say `ready`. Read `re/questions.md` (the default
   question list): add game-specific questions, delete those that cannot apply.
4. `git init && git add -A && git commit -m "re: init"`.
5. Look at the game: `tools/zxrun.py re/orig.z80 --frames 300 --shot 299:/tmp/title.png`,
   view the PNG, write the controls you see into `re/notes.md`.

## Non-standard tapes

`tools/zxtape.py list original/game.tzx` shows the blocks. Then:

- **Where does the game take over?** `tap2sna.py` simulates the real loader
  (accelerators for Speedlock, Alkatraz, Bleepload and others are built in).
  If the simulation stops in the wrong place, use
  `tap2sna.py --sim-load-config trace=/tmp/load.trace original/game.tzx /tmp/x.z80`
  and `grep` the trace (never read it whole) for the last `JP`/`RET` into the game,
  then `--start ADDR` to stop exactly there. Save as `re/orig.z80`.
- **Headerless / turbo blocks**: find the `LD-BYTES` call or custom loader in the
  trace; IX and DE at the call are address and length. Record them in
  `re/notes.md`, patch the payload into `re/image.z80`
  (`snapmod.py --patch ADDR,re/tape/NN.bin re/image.z80 re/image.z80`), add a
  `SAVEBIN` for that range to `src/build.asm` and point the manifest line at the
  `build/` file.
- **Encrypted or compressed payloads**: the skool describes the decrypted code
  (take it from `re/orig.z80` after the decryptor ran). Write
  `scripts/encrypt.py` that turns the assembled block into the tape payload,
  reproduce the decryptor's algorithm exactly, and add to `scripts/rules.mk`:
  ```make
  SCRIPT_OUTPUTS += build/blk05.enc
  build/blk05.enc: build/blocks.stamp scripts/encrypt.py
  	$(PY) scripts/encrypt.py build/blk05.bin $@
  ```
  The loader code itself is a separate skool range or a separate asm file.
- **Protection that cannot reasonably be rebuilt** (e.g. timing-sensitive
  turbo data generated by a mastering tool): keep that tape block as raw data
  in `data/` and say so in `re/notes.md`; byte identity still holds because the
  payload is copied, and the code inside it is still covered by the skool.

Done when `make` prints `IDENTICAL` and `re/notes.md` lists every block with
its address, length and role.
